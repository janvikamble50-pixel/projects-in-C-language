# 🎮 Rock Paper Scissors

A simple Rock Paper Scissors game written in C.

## 🕹️ How to Play

Choose one of the following:

1. Rock
2. Paper
3. Scissors

The computer randomly chooses one option, and the program decides the winner.

## 🧠 Concepts Used

- Variables
- If-else statements
- Random numbers
- `rand()` and `srand()`
- User input
- Basic C programming
