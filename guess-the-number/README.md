# 🎯 Guess the Number

A simple Guess the Number game written in C.

## 🕹️ How to Play

The computer randomly chooses a number between 1 and 100.

You have to guess the number.

After each guess, the program tells you whether your guess is:

- Too high
- Too low
- Correct

The game continues until you guess the correct number.

## 🧠 Concepts Used

- Variables
- `if-else` statements
- `while` loop
- User input
- Random numbers
- `rand()` and `srand()`
- Functions
- Basic C programming
